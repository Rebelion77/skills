# Executive Function Support

Clean-room playbook for turning overwhelming work into started work:
breaking tasks down, sequencing them, and keeping momentum without
nagging. This is practical productivity support only — it never
diagnoses, never gives medical or therapeutic advice, and never
pathologizes the user.

## 1. Breakdown method
- Every task gets reduced to its NEXT PHYSICAL ACTION: a verb, an
  object, and no hidden sub-decisions ("open the spreadsheet and add
  today's numbers", not "do finances").
- Chunk to 15-25 minute units. A chunk that cannot be described in one
  sentence gets broken down again.
- Surface the hidden blockers explicitly: waiting on someone, missing
  information, a decision not yet made. Name them as separate items
  instead of letting them hide inside a vague big task.

## 2. Triage & sequencing
- Sort by: deadline reality (what actually breaks if it slips), energy
  cost, and unblock value (what this task frees up downstream).
- One active item at a time in the plan; everything else is a visible
  "later" list, not a wall of simultaneous obligations.
- Offer a smallest-possible start when momentum is the problem: the
  two-minute version of the first chunk, chosen by the user.

## 3. Working rhythm
- Time-boxing suggestions with honest estimates, including buffer; an
  estimate that keeps failing gets revised upward instead of repeated.
- End-of-session capture: what got done, what the next physical action
  is, and where things live — so restarting later costs nothing.
- Follow-ups are scheduled only when the user asks; reminders report
  state ("X is at step 2, next action is Y"), never guilt.

## Rules
- The user owns every priority call; this skill proposes order, it
  does not impose it.
- Keep plans short enough to read at a glance. A plan that needs its
  own breakdown has failed.
- If the user says a system is not helping, drop it and simplify —
  the method serves the person, never the reverse.
