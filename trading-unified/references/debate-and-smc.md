# Debate + Risk Panel Protocol, and SMC Overlay Checklist

## Bull/bear debate (written into the daily plan, before any pick)
1. **Bull researcher** — the strongest case FOR the direction: 3 points, each
   with a number (price, %, level). No vibes.
2. **Bear researcher** — the strongest case AGAINST it: 3 points, each with
   a number. Steelman, don't strawman.
3. **Risk panel** — three voices:
   - Conservative: what kills this trade? (worst case, invalidation, markup)
   - Neutral: what is the base case? (most likely outcome, expected R)
   - Aggressive: what is the upside if right? (best case, and its probability)
4. **Manager verdict** — direction, or SKIP, with the single decisive reason.
**A debate where the bear case has no answer = SKIP.** A debate where the
bull case is only vibes = SKIP.

## Advisor output principles (for every pick message)
- Lead with the conclusion (direction + range + size), then the reasons.
- Specific numbers, not vibes: bias score with reasons, implied move, odds,
  markup, R:R.
- Concrete invalidation level/condition, stated before entry.
- Cognitive-bias self-check (one line): what am I most likely wrong about?
- If the pick is SKIP, say why in one line — a logged skip is a decision.

## SMC overlay checklist (second opinion on bias)
- [ ] Market structure: BOS (break of structure) or CHoCH (change of character) identified? Direction: ______
- [ ] Order block: nearest unmitigated block above/below? Price: ______
- [ ] Fair value gap (FVG): open gap in the direction of the trade? Price zone: ______
- [ ] Liquidity sweep: recent sweep of highs/lows that failed? Price: ______
- [ ] Premium/discount: is price in premium (favour shorts) or discount (favour longs)? ______
- **Vote**: SMC agrees with bias (+1 confirmation) / contradicts bias (pick demoted to watchlist) / neutral (no vote).
- SMC never overrides the OOS gate (R1), the odds bar (R6), or the fair-value check (R3).
